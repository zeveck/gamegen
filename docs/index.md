# gamegen

Describe a game, and [gamegen](https://github.com/zeveck/gamegen) makes it:
a [Claude Code](https://claude.com/claude-code) plugin that plans the game,
has it reviewed, makes the art, animation, music and sound, builds it,
play-tests it, and hands you a link to play.

- **[Get gamegen on GitHub](https://github.com/zeveck/gamegen)**: what it
  does, how to install it, and how to use it.
- **[Putting your game on Steam](steam-guide/)**: from a finished game to a
  release on Steam.
- **[Games made with gamegen](https://synapticnoise.com/)**: play them in
  your browser.
